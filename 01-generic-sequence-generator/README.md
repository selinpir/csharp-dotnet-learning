# Generic Sequence Generator

.NET 8 ile geliştirilmiş, generic yapılar ve nesne yönelimli programlama
prensiplerini kullanan bir dizi üretme projesidir.

Projede interface, abstract class, inheritance, polymorphism, generics
ve delegate kullanılarak farklı türlerde diziler üretilmektedir.

## Desteklenen Diziler

- Fibonacci dizisi
- Tamsayı recurrence dizisi
- Ondalıklı sayı dizisi
- Karakter dizisi
- Delegate ile tanımlanabilen generic diziler

## Kullanılan Teknolojiler

- C#
- .NET 8
- Generic Types
- Interfaces
- Abstract Classes
- Inheritance
- Delegates
